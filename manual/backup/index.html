Backup

salvar uma cópia de tudo o que você lançou, e trazer de volta se precisar.

Como chegar: ⋮ › Backup.

Por que isso importa mais aqui do que em outros apps#

O Fólio não tem servidor. Seus dados estão no seu celular e em mais lugar nenhum. Se você trocar de aparelho, perder o celular ou desinstalar o app sem backup, os lançamentos vão junto.

Faça um backup manual e guarde fora do celular.

A tela tem duas partes#

1. Backup manual#

Você exporta um arquivo e escolhe onde guardar (Drive, OneDrive, cartão…).

Como exportar:

  1. Decida se quer Proteger com senha (interruptor).
  2. Se sim, digite uma senha de no mínimo 8 caracteres.
  3. Toque em Exportar.
  4. O Android abre o seletor de pastas; escolha o destino e confirme.

O nome do arquivo já vem com a data: carteira-backup-AAAA-MM-DD.json (sem senha) ou carteira-backup-AAAA-MM-DD.foliobak (com senha).

⚠️ Não há recuperação de senha. A própria tela avisa: se você esquecer a senha, o arquivo não pode ser restaurado. Ninguém — nem o suporte — consegue abrir.

Como restaurar:

  1. Toque em Importar.
  2. Escolha o arquivo.
  3. Se ele for protegido, o app pede a senha.
  4. Aparece a confirmação "Confirmar restauração", dizendo o que o arquivo contém.
  5. Toque em Substituir tudo.

🔴 Restaurar substitui tudo. Todas as suas operações atuais são apagadas e trocadas pelas do backup. Não é mesclagem. Não dá para desfazer.

2. Backups automáticos#

O app guarda 1 backup por dia, os 5 mais recentes, cifrados no aparelho. É uma rede de segurança contra erro e corrupção de dados.

Cada item da lista tem um botão para restaurar. Vale o mesmo alerta: restaurar substitui tudo.

Eles ficam no celular. Não protegem contra perder ou trocar o aparelho — para isso, só o backup manual guardado fora.

Perguntas frequentes#

Troquei de celular. Como levo minha carteira?#

  1. No celular antigo: ⋮ › Backup › Exportar e salve no Drive.
  2. Instale o Fólio no celular novo e aceite o aviso legal.
  3. ⋮ › Backup › Importar, escolha o arquivo do Drive.
  4. Confirme Substituir tudo (o app novo está vazio mesmo).

O que vai dentro do backup?#

Todos os seus lançamentos: compras, vendas, proventos, eventos corporativos, aportes em R$ e US$, posições de patrimônio com os saldos mensais e compras de dólar.

O backup é seguro para guardar no Drive?#

O arquivo contém os seus dados de carteira. Se isso te preocupa, ligue Proteger com senha antes de exportar — aí o arquivo sai cifrado e só abre com a senha.

O Android também faz backup do app sozinho?#

Sim, se o backup automático do Android estiver ligado no aparelho: o próprio sistema pode copiar os dados do app para o seu Google Drive, de forma criptografada. Isso é do Android, não do Fólio, e o desenvolvedor não tem acesso a esse backup. Está descrito no Aviso legal, item 5.

Restaurei o backup errado. E agora?#

Se você tem um backup mais recente, restaure ele. Se não, veja se algum dos backups automáticos do aparelho serve. Fora isso, não há como voltar.

O que costuma confundir#

"Importar" aqui não é a mesma coisa que "Importar CSV / B3". Este importa um backup e substitui tudo. O outro acrescenta operações. São telas diferentes.

Exportar não apaga nada — é só uma cópia.

O que esta tela NÃO faz#

  • Não envia backup para nuvem nenhuma automaticamente. Você escolhe o destino a cada exportação.
  • Não mescla backups. É sempre substituição total.
  • Não recupera senha esquecida.
  • Não faz backup agendado para fora do aparelho.
